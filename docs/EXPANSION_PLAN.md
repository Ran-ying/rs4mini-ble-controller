# 非相机能力扩展计划

2026-10-15，用户在 0.6.0 交付后要求继续完成其余非相机能力，沿用自主开发、离线验证、实机统一后验的约定。此前完成的计划见 `IMPLEMENTATION_PLAN.md`。

- [x] 自动重连：显式启用、有界退避、状态通知、手动断开/关闭取消；绝不恢复旧运动。
- [x] 轨迹：按单调时钟插值速度关键帧、过期帧跳过而不突发补发、超时/停止/断线清理；多路点关节定位与停留。
- [x] 单轴返回用户保存位置，与固件回中分别命名。
- [ ] 研究并实现具有本机证据的真正单轴回中命令。
- [ ] 原生绝对角、模式、休眠/唤醒及设备查询：逐项核对原始协议来源；支持有依据的实验命令与响应关联，不能把其他型号的命令标为本机已验证。
- [x] 四元数数学与可配置分量约定、状态字段解释；保留坐标约定未实测的事实。
- [x] Python、Web、macOS 同步适合其端的能力、文档与离线检查。
- [x] 更新统一实机清单、版本及可安装包；安装后回归通过。源码与持续交接说明保存在本仓库，入口见 `PROJECT_STATUS.md`；可安装包已在聊天交付。

设备证据不足不会被离线测试替代；本计划完成时仍需明确区分已验证命令、实验支持及无法确认的固件能力。相机/视觉、发布到 npm 或远端二进制版本不在范围内。开发期间不扫描、不连接、不移动硬件。

## 架构整理

- [x] 明确设备 SDK、运动组合层与应用层的责任及 API 归属，见 `ARCHITECTURE.md`。
- [ ] 保持现有 API 兼容，将统一控制器中的设备访问和运动组合提取为可分别使用的模块；保留统一停止/取消与写入互斥。

## 阶段进展

Node/Python/共享 Web SDK 已实现自动重连、速度关键帧、逐点定位、保存位置返回、显式四元数顺序数学转换。
实验配置已加入原生角度、速率、休眠/唤醒、限定查询与被动额外状态，均标明其他型号来源和本机未验证。
普通 `moveTo()` 继续使用此前已确认的速度协议和关节映射。

原生面板和 Web 页面入口已补齐；能力清单见 `CAPABILITIES.md`，新增可显式运行的 Node/Python 示例和四端共用 JSON 格式。
本轮完整离线检查和实际包安装测试已通过，数字与范围见 `VALIDATION.md`。
仍需现场验证记录。真实单轴回中、跟随模式、校准/电机调参和原生轨迹仍缺少本机证据，
不能将以上进展当作本计划全部完成。

已开始官方 Ronin APK 静态分析，找到重置/模式、Ronin 参数、校准等候选业务类；业务负载仍未还原。
