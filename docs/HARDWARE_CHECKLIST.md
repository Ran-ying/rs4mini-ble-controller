## 每次测试前记录

日期、macOS/浏览器/运行时、固件版本、跟随模式、负载与平衡、周围运动空间、摇杆速度设置。退出其他控制稳定器的程序，每次只运行一个控制端。

先确认平衡、解锁和无遮挡；先做低速小幅单轴，再做多轴。保持能够手动关闭稳定器。所有 SDK 测试使用 `try/finally` 和 `close()`；中位停止帧不能替代固件急停。
