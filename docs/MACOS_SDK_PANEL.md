## 使用

1. 连接稳定器；右侧点击“启用 ronin-2.2.2 来源”。此动作选择已研究的来源格式，不自动查询/写入，不代表设备识别成功。
2. 选择分组、命名操作。多数读取筛选项留空表示不筛选；电机数值读取必须选择轴与参数，表单仍选择单项，SDK已通过逐项汇总读取。设置的可选字段留空表示不修改。必填选择没有默认写值。
3. 填写参数、超时；查询直接点击执行。写入须显式勾选允许本次请求；电机/校准/恢复等维护请求另显示具体参数供确认。
4. “请求与结果”保留操作名、请求参数、真实返回或错误；ACK不当作实际效果或完成。需要回读时另行执行读取，不自动写后回读/保存/重试。
5. “被动状态”显示十类缓存及原始/未知/验证字段。null表示尚无状态，接收不触发查询或订阅；断线沿用SDK清空，不使用旧状态兜底。
6. “查看订阅键”只列出SDK发现目录；“单次命名参数订阅”输入非空逗号分隔键。推送停止不是程序停止，没有后台续订或重连重放。
7. 停止按钮取消主机操作并发送现有中位；不保证中止固件校准/程序。原始degree-info使用既有固定3秒查询，单独展示接收的4:1E原始消息，不假定其业务字段。

没有设备时可浏览操作和填写表单，执行/写入不可用。表单值必须为有限数字、严格整数/布尔或允许枚举；沿用SDK的命名参数范围，拒绝未知订阅键、重复键、空设置与任意写帧。

## 实现及验收边界

`macos/RSSDKActions.m`只负责目录、严格表单转换、复用纯SDK参数校验和编译期明确的方法调用；不通过selector字符串开放任意方法。`RSSDKPanel.m`负责呈现、一次性写入开关、维护确认和错误/状态显示，不编码/写入BLE帧。`tools/check-boundaries.py`新增GUI不得绕过设备层的检查。

适配器测试用RecordingGimbal代理逐项核对43个方法的分发、失败入口、超时/来源/连接门槛、布尔false、未选字段、参数范围及原始字节显示，不创建CBCentralManager。现有SDK生命周期/编解码测试仍作为底层保障。AppKit离线布局检查覆盖全部43个表单在650×820面板中的布局；该离线检查不连接设备。2026-10-20另已在生产GUI实测连接、反馈、灵敏度查询、degree-info及断开；43项并未逐项实机验收，详见[实机记录](HARDWARE_SESSION_2026-10-20.md)。

本次不改变协议清单及49项范围，不提升deviceVerified或physicalCompletionVerified，不开放04:0A/0D/11/2C/40、原生程序执行、激活写入或新增高级任务。真实设备效果、订阅、相机隔离、校准/恢复范围、持久化与固件中止仍遵循HARDWARE_CHECKLIST.md。旧专题中的“无调参按钮”是当时交付状态，以本页为当前GUI入口。

复现：仓库根目录运行 `sh tools/check-offline.sh`（含270项GUI适配器检查及原生构建）。有桌面会话的macOS可另运行 `sh macos/check-layout.sh`，只创建离屏AppKit视图和记录代理，不启动生产程序、不创建蓝牙管理器。
