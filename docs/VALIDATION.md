开发会话在 2026 年 9 月使用 macOS 与 DJI RS 4 Mini 完成。未记录稳定器固件版本和完整负载参数，
因此以下结果仅代表当时安装和设置，不构成全负载精度保证。设备名称后缀、UUID 和原始日志不公开。

| 测试 | 起点关节角 | 目标关节角 | 目标端最后反馈 | 返回端最后反馈 | 返回误差 |

| Pan 20° | -157.84° | -137.84° | -138.40° | -157.48° | 0.36° |

Pan 5° 去程约 3.0 秒、返程约 2.8 秒；Pan 20° 约 5.0 / 4.8 秒；
Tilt 12° 约 4.0 / 3.7 秒；Roll 12° 约 6.0 / 2.8 秒。
读取值是闭环宣布进入容差时的反馈，尚未证明停止并完全稳定后的角度相同。

历史实机还确认了蓝牙直连、Pan/Tilt/Roll 速度控制、停止、三轴回中和 FFF4 通知读取。
原始反馈的静止、分轴往返与手柄转动用于验证 `04:05` 映射。四元数分量顺序没有验证。

Node v0.5.0 的取消/互斥补丁有离线假适配器覆盖；前面的硬件定位读数来自其前一版控制循环，
不应将补丁称为已经重新完成硬件验证。

## 可重复的离线检查

```sh
cd node
npm ci
npm test
npm pack --dry-run
```

测试内容：黄金帧、CRC 与分片重组、遥测映射、缓存直接连接与扫描回退、
读取新反馈、位置控制方向、取消/冲突操作、关闭扫描。
假适配器测试不验证无线链路、电机响应、机械限位或闭环物理稳定性。

Python 在安装依赖后运行：

```sh
cd python
python -m unittest discover -s tests -v
```

Node 的 `.d.ts` 已随包提供；历史整理没有 TypeScript 编译器验证记录。
